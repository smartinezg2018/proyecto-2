# Activos

Modulo para inventario, estados, costos, proveedores y trazabilidad de activos.

Capas: `domain`, `application`, `infrastructure` y `presentation`.

## Cobertura actual

- CRUD de activos por edificio, cambio de estado e historial.
- Proveedores: catálogo, registro y asociación a un activo (HU-018).
- Costos: adquisición (HU-019) y consolidación/consulta de operación (HU-020).
